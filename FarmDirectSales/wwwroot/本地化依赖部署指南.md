# 农产品直销系统 - 本地化依赖部署指南

## 🎯 目标
将项目中的CDN依赖本地化，解决网络访问和性能问题。

## 📋 当前依赖分析

### CDN依赖清单
| 依赖库 | 当前CDN | 用途 | 文件大小 |
|--------|---------|------|----------|
| Bootstrap 5.1.3 | jsdelivr | UI框架 | ~200KB |
| Font Awesome 6.0 | cloudflare | 图标字体 | ~100KB |
| Axios | jsdelivr | HTTP请求 | ~50KB |
| jQuery 3.6.0 | jsdelivr | DOM操作 | ~85KB |
| SweetAlert2 | jsdelivr | 弹窗组件 | ~150KB |

### 网络问题分析
1. **国外CDN在中国访问慢**
2. **离线环境无法使用**
3. **网络不稳定影响用户体验**
4. **HTTPS混合内容警告**

## 🚀 部署步骤

### 步骤1: 安装Node.js依赖管理
```bash
# 进入wwwroot目录
cd FarmDirectSales/wwwroot

# 初始化npm项目
npm init -y

# 安装依赖
npm install bootstrap@5.1.3 @fortawesome/fontawesome-free@6.0.0 axios@0.27.2 jquery@3.6.0 sweetalert2@11.0.0

# 安装开发依赖
npm install --save-dev fs-extra glob
```

### 步骤2: 复制依赖文件到本地
```bash
# 运行复制脚本
node copy-dependencies.js
```

### 步骤3: 更新HTML文件中的引用
```bash
# 批量更新CDN链接为本地路径
node update-cdn-to-local.js
```

### 步骤4: 验证更新结果
检查lib目录结构：
```
wwwroot/
├── lib/
│   ├── bootstrap/
│   │   ├── css/bootstrap.min.css
│   │   └── js/bootstrap.bundle.min.js
│   ├── fontawesome/
│   │   ├── css/all.min.css
│   │   └── webfonts/
```

## 🔧 手动替换方案

如果自动化脚本不可用，可以手动操作：

### 1. 下载依赖文件
```bash
# 创建lib目录
mkdir -p lib/{bootstrap/{css,js},fontawesome/{css,webfonts},axios,jquery,sweetalert2}

# 下载Bootstrap
wget https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/css/bootstrap.min.css -O lib/bootstrap/css/bootstrap.min.css
wget https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/js/bootstrap.bundle.min.js -O lib/bootstrap/js/bootstrap.bundle.min.js

# 下载Font Awesome
wget https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0-beta3/css/all.min.css -O lib/fontawesome/css/all.min.css

# 下载其他依赖...
```

### 2. 更新HTML引用
将所有HTML文件中的CDN链接替换为：
```html
<!-- 旧的CDN引用 -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/js/bootstrap.bundle.min.js"></script>

<!-- 新的本地引用 -->
<link href="/lib/bootstrap/css/bootstrap.min.css" rel="stylesheet">
<script src="/lib/bootstrap/js/bootstrap.bundle.min.js"></script>
```

## 🌏 国内CDN替代方案

如果希望继续使用CDN，推荐使用国内服务：

### BootCDN (推荐)
```html
<!-- Bootstrap -->
<link href="https://cdn.bootcdn.net/ajax/libs/bootstrap/5.1.3/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.bootcdn.net/ajax/libs/bootstrap/5.1.3/js/bootstrap.bundle.min.js"></script>

<!-- Font Awesome -->
<link href="https://cdn.bootcdn.net/ajax/libs/font-awesome/6.0.0-beta3/css/all.min.css" rel="stylesheet">

<!-- Axios -->
<script src="https://cdn.bootcdn.net/ajax/libs/axios/0.27.2/axios.min.js"></script>
```

### 又拍云CDN
```html
<link href="https://unpkg.com/bootstrap@5.1.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://unpkg.com/bootstrap@5.1.3/dist/js/bootstrap.bundle.min.js"></script>
```

## 🔍 故障排除

### 常见问题
1. **字体图标不显示**
   - 检查webfonts目录是否复制完整
   - 确认CSS文件中的字体路径正确

2. **样式丢失**
   - 确认CSS文件路径正确
   - 检查文件是否完整下载

3. **JavaScript功能异常**
   - 确认JS文件加载顺序
   - 检查浏览器控制台错误

### 性能优化建议
1. **启用GZIP压缩**
2. **设置静态文件缓存**
3. **使用CDN加速静态资源**
4. **按需加载非关键CSS/JS**
