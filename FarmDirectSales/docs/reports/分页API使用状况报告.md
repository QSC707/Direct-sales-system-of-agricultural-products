## 🔧 后端分页API列表

### ✅ 已实现的8个分页API

| API端点 | 功能描述 | 状态 |
|---------|----------|------|
| `GET /api/Product` | 产品列表分页 | ✅ 已实现 |
| `GET /api/Farmer` | 农户列表分页 | ✅ 已实现 |
| `GET /api/Farmer/{farmerId}/products` | 指定农户的产品分页 | ✅ 已实现 |
| `GET /api/Order/farmer/{farmerId}` | 农户订单分页 | ✅ 已实现 |
| `GET /api/Order/user/{userId}` | 用户订单分页 | ✅ 已实现 |
| `GET /api/OrderGroup/user/{userId}` | 用户订单组分页 | ✅ 已实现 |
| `GET /api/Admin/users` | 管理员用户管理分页 | ✅ 已实现 |
| `GET /api/Admin/users/role/{role}` | 按角色查询用户分页 | ✅ 已实现 |

### 📝 分页参数规范
所有分页API支持以下参数：
- `page`: 页码（从1开始）
- `pageSize`: 每页大小（默认20条）
- 各种筛选参数（keyword、category、status等）

### 📊 分页响应格式
```json
{
  "code": 200,
  "message": "成功",
  "data": [...], // 当前页数据数组
  "pagination": {
    "currentPage": 1,
    "pageSize": 20,
    "totalCount": 150,
    "totalPages": 8,
    "hasPrevious": false,
    "hasNext": true
  }
}
```

## 🛠 技术实现特点

### 🎨 前端分页控件特性
- **智能省略号**: 页码过多时自动显示省略号
- **响应式设计**: 移动端友好的分页控件
- **加载状态**: 分页切换时的加载指示器
- **错误处理**: 网络错误时的友好提示
- **URL状态**: 某些页面支持URL参数保持状态

### 🔧 后端分页实现
- **数据库级分页**: 使用EF Core的Skip/Take
- **性能优化**: 避免COUNT(*)查询的性能问题
- **参数验证**: 页码和页面大小的合法性验证
- **统一响应**: 标准化的分页响应格式

### 📱 用户体验优化
- **平滑加载**: 页面切换时的loading状态
- **智能筛选**: 筛选条件变更时自动回到第一页
- **状态保持**: 某些筛选条件在页面刷新后保持
- **无障碍访问**: 符合ARIA标准的分页控件
