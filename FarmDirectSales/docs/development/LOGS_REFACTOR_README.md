## 📈 使用指南

### 1. **访问日志管理**
```
http://localhost:5000/pages/admin/logs.html
```

### 2. **查看实时统计**
- 页面顶部显示总日志数、成功操作数、错误日志数和成功率
- 数据自动实时更新

### 3. **筛选和搜索**
- 使用搜索框进行关键词搜索
- 选择日志级别和操作类型进行筛选
- 设置日期范围查看特定时间的日志
- 查看活动筛选标签，快速清除筛选条件

### 4. **查看详细信息**
- 点击任意日志条目的"查看详情"按钮
- 查看完整的日志信息和相关日志
- 分析请求性能和状态信息

### 5. **统计分析**
- 切换到"统计分析"标签页
- 查看日志趋势图、操作类型分布、活跃用户等
- 分析常见错误和系统运行状况

### 6. **日志清理**
- 点击"清理日志"按钮
- 设置保留天数（最少7天）
- 确认清理操作释放存储空间

## 🔧 API使用示例

### 获取日志列表
```javascript
// 基础查询
GET /api/Log?page=1&pageSize=20

// 高级筛选
GET /api/Log?page=1&pageSize=20&keyword=登录&logLevel=ERROR&actionType=POST&startDate=2023-12-01&endDate=2023-12-31

// 排序
GET /api/Log?page=1&pageSize=20&sortBy=actionTime&sortOrder=desc
```

### 获取统计数据
```javascript
// 默认最近7天统计
GET /api/Log/statistics

// 指定时间范围
GET /api/Log/statistics?startDate=2023-12-01&endDate=2023-12-31
```

### 获取日志详情
```javascript
GET /api/Log/123
```

### 清理旧日志
```javascript
DELETE /api/Log/cleanup?daysToKeep=30
```
