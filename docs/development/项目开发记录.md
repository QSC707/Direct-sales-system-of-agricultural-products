### 2. Bootstrap 5兼容性修复

#### 2.1 配送设置界面优化
**问题描述**: 新建预设和编辑预设模态框的关闭按钮使用了Bootstrap 4语法

**解决方案**:
```html
<!-- 修复前 (Bootstrap 4) -->
<button type="button" class="close" data-dismiss="modal" aria-label="Close">
    <span aria-hidden="true">&times;</span>
</button>

<!-- 修复后 (Bootstrap 5) -->
<button type="button" class="btn-close" data-bs-dismiss="modal" aria-label="Close"></button>
```

**修改文件**:
- `FarmDirectSales/wwwroot/pages/farmer/delivery-settings.html`

### 3. 服务器管理和调试

#### 3.1 端口冲突问题解决
**问题**: 多次遇到端口5004占用冲突
```bash
System.IO.IOException: Failed to bind to address http://127.0.0.1:5004: address already in use.
```

**解决方案**:
```bash
# 查找并终止占用端口的进程
lsof -ti:5004 | xargs kill -9

# 重新启动服务器
cd FarmDirectSales
dotnet run
```

### 5. 项目部署指南

#### 5.1 环境要求
**必需软件**:
- Visual Studio 2022 (包含ASP.NET和Web开发工作负载)
- .NET 9.0 SDK
- SQL Server Express LocalDB 或完整 SQL Server

#### 5.2 项目获取和配置
**代码获取**:
```bash
# Git克隆 (推荐)
git clone [仓库地址]

# 或下载ZIP包解压
```

**NuGet包还原**:
```bash
dotnet restore
```

**数据库配置**:
```json
// appsettings.json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=FarmDirectSalesDB;Trusted_Connection=true;"
  }
}
```

**数据库迁移**:
```bash
dotnet ef database update
```

#### 5.3 运行配置
**启动项目**:
```bash
cd FarmDirectSales
dotnet run
```

**端口设置**: 默认5004端口 (可在launchSettings.json中修改)
